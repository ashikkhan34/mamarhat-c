🛍️ ## MAMATHAT — Modern Ecommerce Website (MERN Stack)

A fast, modern, and user-friendly ecommerce platform built using the MERN Stack.
Beautiful UI, powerful backend, and secure authentication — designed for real-world ecommerce.


#Tech Skills Used
- 🚀 Next.js
- 🎨 Tailwind CSS
- 🔥 Next auth Authentication 
- 🌐 Axios
- 🟢 Node.js
- ⚙️ Express.js
- 🍃 MongoDB
- 🔐 JWT Authentication
- 🖼️ Imagebb (Product Image Upload)



👤 #User Features
- 🔑 Login / Registration  
- 🔐 Google Authentication  
- 🔍 Product Search & Category Filters  
- 📝 Product Details Page  
- 🛒 Add / Remove / Update Cart Products  
- 💳 Checkout System  
- 📦 Place Orders & Track Orders  
- 📱 Fully Responsive UI

****- 🆕 Admin Features
- ✏️ Edit / Delete Products  
- 📁 Manage Inventory & Stock  
- 📦 Manage Orders  
- 👥 Manage Users  
- 📊 Dashboard Analytics
